# RISC‑V Beginner Guide  
[Resources provided by Imagination Technologies]

This repository provides a quick and practical introduction to RISC‑V development for beginners.  
It is based on the open‑source course from Imagination Technologies, combined with additional documentation and files that I have prepared to simplify the learning process.

## Before You Begin
Please read the included documentation **before running any `.sh` scripts**.  
Some scripts require path adjustments as described in the documentation; otherwise they will not function correctly.

## Contents
 Introductory RISC‑V materials  
 Setup instructions and environment configuration  
 Example scripts and exercises  
 Additional notes and clarifications for beginners
